# 資金繰り表

月ごとの現金の流れ(収入・補填・支出・貯金)を入力して、月末の所持金を確認する個人用Webアプリ。
画面は `index.html` 1枚(GitHub Pages)、データは Google スプレッドシート(Apps Script 経由)に保存します。
iPhone と Mac の両方で同じデータを見られます。

月末所持金 = 月初の現金 + 収入 + 補填 − 支出 − 貯金・投資
月初の現金は、空欄なら前月の月末所持金を自動で引き継ぎます。数字を入れればその値が優先されます(実際の現金に合わせて直せます)。

## 使い方

- 金額欄をタップすると全選択されるので、そのまま打ち替えられます。
- 入力したあと、画面下の「保存」を押すとスプレッドシートに保存されます。保存前の入力は端末に下書きとして残り、次に開いたときに復元できます。
- 新しい月は「初期値を入れる」で給料・楽天カード・家賃が入ります(押すまでは入りません)。
- 月が終わったら、翌月以降にその月を開いて「確定する」を押します。確定した月の金額欄は読み取り専用になります(「確定を解除」で戻せます)。月初の現金は確定後も編集できます。

## セットアップ

`index.html` の `GAS_URL` に Apps Script の Web アプリ URL を埋め込んであるので、**端末ごとの設定は不要**です。iPhone も Mac も、ページを開くだけで同じスプレッドシートにつながります。
スプレッドシートは最初のアクセスで自動的に初期化されます(2026年11月・12月のデータと初期値が入ります)。

最初の1回だけ、Apps Script の権限をスプレッドシートの持ち主が許可する必要があります。

1. スプレッドシートの「拡張機能 → Apps Script」を開く。
2. 関数 `seed` を選んで「実行」し、「権限を確認」→ 自分のアカウントを選び →「詳細」→「(安全ではないページ)に移動」→「許可」。
3. 以後は画面から読み書きできます。

最初から作り直す場合は、新しいスプレッドシートに `Code.gs` を貼って「デプロイ → 新しいデプロイ」(種類=ウェブアプリ、実行=自分、アクセス=**全員**)し、できた URL を `GAS_URL` に入れてください。

## コードを直したとき

「デプロイ → デプロイを管理 → 編集(鉛筆) → バージョン: 新バージョン」で更新します。**新しいデプロイを作ると URL が変わる**ので、通常は上書き更新にしてください。

## 注意

- 合言葉は設けていません。Web アプリの URL は `index.html` に含まれ、このリポジトリは公開なので、URL を知った人は誰でもスプレッドシートを読み書きできます(金額は個人用の小さなもの、という前提で割り切っています)。悪用された場合は、新しいデプロイを作って URL を変え、旧デプロイを削除し、`GAS_URL` を差し替えてください。
- `Yan-ui11.github.io` の同じオリジンでは、他の Pages サイトとブラウザの保存領域(localStorage)が共有されます。このオリジンでは第三者のスクリプトを読み込まないでください。

## スプレッドシートの中身

- `入力`: 1セル=1行(月 / 項目 / 区分 / 金額 / 更新)。月は `202611` のような数値。区分 `確定` は月の確定印です。
- `設定`: 初期値(区分 / 項目 / 金額)。ここを書き換えると「初期値を入れる」の内容が変わります。
- `月次`: 上から自動計算した集計(数式。直接編集しないでください)。
